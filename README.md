# LabTrack frontend

Initial React frontend for the AutoGrader & Lab Submission Portal. The current slice includes the responsive LabTrack sign-in flow and placeholder student and lecturer dashboards.

## Run locally

```bash
cd FrontEnd
npm install
npm run dev
```

Open the local URL shown by Vite. Select a role, enter a valid email and any non-empty password, then sign in to reach the matching placeholder dashboard.

## Available checks

```bash
npm run lint
npm run build
```
